How to get your Google Sheet URL:

  1. Open your Google Sheet containing student data
  2. Click File → Share → Publish to web
  3. Select Entire document and Comma-separated values (.csv)
  4. Click Publish and copy the generated link
  5. Paste the link in the field below

Google Sheet URL

The URL must be published as CSV (File → Share → Publish to web → CSV)

Important Information:

After syncing students, the Finance module will automatically verify student records. If a student doesn't exist in the database, payment cannot be recorded - users will be directed to contact the system administrator.

Expected Column Headers

Your Google Sheet should have these columns (headers are case-insensitive):

  • Student ID (or ID)
  • First Name
  • Last Name
  • Gender
  • Date of Birth
  • Class
  • Section
  • Parent Name
  • Parent Phone
  • Parent Email
  • Address
