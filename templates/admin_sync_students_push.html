How to Export to Google Sheets:

  1. Enter the URL of your Google Sheet (must be published as CSV)
  2. Click "Export Students" to generate a CSV file
  3. Open your Google Sheet
  4. Go to File → Import → Upload
  5. Upload the exported CSV file
  6. Choose "Replace current sheet" to update existing data
